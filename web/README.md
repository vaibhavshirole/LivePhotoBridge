# LivePhotoBridge Web

A fast, zero-cloud web application for transforming Apple Live Photo pairs (`.HEIC` / `.JPG` + `.MOV`) into native Google Motion Photos (`.MP.HEIC` or `.MP.JPG`) playable on Google Pixel and Google Photos.

---

## Features

- **100% Client-Side In-Browser Muxing**: Fast, privacy-first conversion. Photos never upload to an external cloud.
- **Drag & Drop Unified Input**: Drop individual photos/videos or entire camera roll folders.
- **Automatic Live Photo Pairing**: Automatically groups photos and matching motion video streams.
- **Real-Time Progress Bar**: Smooth percentage tracking with live step descriptions.
- **ZIP Bundle Download**: Download all processed Motion Photos in a single `.zip` file with one click.
- **Mobile QR Code Sharing**: Scan the on-screen QR code with your iPhone or Android camera to download the generated Motion Photos directly to your phone over your local Wi-Fi.
- **Interactive Motion Photo Preview**: Test and play back the motion photo right inside the browser.

---

## Running the Web App

### Option 1: Quick Start with Local Server (Recommended for Mobile QR Code Transfer)
Run the lightweight, zero-dependency Node server:

```bash
# From the LivePhotoBridge root directory:
cd web
npm start
```

Or directly:
```bash
node web/server.js
```

Open your browser to:
- **Local:** `http://localhost:3000`
- **Network (for phone/tablet):** `http://<your-local-ip>:3000` (printed in terminal)

### Option 2: Standalone Static HTML
You can also directly open `web/index.html` in Chrome, Safari, Edge, or Firefox without any server running. Conversions and ZIP downloads will run 100% in-browser.

## Output Verification

Motion Photos generated by LivePhotoBridge Web contain the canonical Google Camera metadata specifications:
- `MicroVideo = 1`
- `MicroVideoOffset = <video byte offset>`
- `MicroVideoPresentationTimestampUs = <presentation timestamp>`
- `MotionPhoto = 1`
- `MotionPhotoPresentationTimestampUs = <presentation timestamp>`
- `MotionPhotoVersion = 1`

Verify with ExifTool:
```bash
libs/exiftool/exiftool -G1 -a -s -XMP-GCamera:all /path/to/IMG_XXXX.MP.HEIC
```
